# 观局 · RangeMind

**看清范围，想透每一步。**

面向已有现金局基础的玩家，观局把局面求解、范围与组合数研究、中文解释和长期训练记录放在同一个本地工作台里。研究的目标不仅是获得一个动作答案，而是能够说明：哪些组合支持这个动作、对手加注后会怎样、改变一个假设后结论是否仍成立，以及怎样把结论转化为下一次实战的可检验判断。

> **提交与硬件说明：**本项目用于第三届 NVIDIA DGX Spark Hackathon 项目展示。开发和演示环境是 Windows、Intel i9-14900KF、64 GB 内存、NVIDIA RTX 4090 24 GB。**根据项目团队最新确认，当前版本已在 NVIDIA DGX Spark 完成全部功能测试并通过。** 该功能测试状态依据团队确认，并非本机重新运行的结果。本文既有性能数字来自 RTX 4090 测试环境；DGX Spark 性能基准未在本文报告。

## 主要功能

| 功能 | 学习目标与实现 |
|---|---|
| 便捷输入与现场记谱 | 中文结构化输入、GG/PokerStars 文本手牌导入、2–9 人现金局逐动作记谱；核验行动顺序、筹码守恒、短全下和返还，把历史决策位置还原到求解输入。 |
| 范围与组合数 | 169 格范围编辑、具体组合和频率、公共牌移除、阻断效应与联合兼容性；区分原始权重和节点后验到达概率。 |
| 多人权益研究 | 2–9 人权益、多个范围阶段、公共牌变化比较；CUDA 并行采样并显示区间和抽样限制。权益结果不冒充策略答案。 |
| 策略与行动树 | 支持下注、跟注、弃牌、加注和再加注，查看节点策略、范围、行动 EV 与真实后续响应。 |
| 多人求解 | 自研河牌 CPU 求解器支持 2–6 人，转牌至河牌支持 2–4 人；实验 GPU 河牌路径支持 2–3 人并由 CPU 独立复核。完整翻牌至河牌仅接入单挑引擎。 |
| 动态平衡 | 为整个范围分配动作频率；同时衡量对固定参考策略的损失与对手解除锁定后的最佳响应，用具体响应路径说明可利用点。 |
| 反事实实验 | 改一张公共牌或一项范围/响应假设，重新求解 A/B 模型；拆解终局贡献与机制，避免把相关变化直接称为因果。 |
| 中文解释 | 由程序重建 EV、终局和实际后续行动，再组织成教案；可选本地语言模型选择教案段落，数值与扑克结论由可核验规则提供。 |
| 连续决策训练 | 隐藏未来牌与不应知道的对手底牌，连续下注/加注、暂停恢复，记录理由、信心及是否看过答案。 |
| 学习闭环 | 预测→证据→有条件的规则→实战观察→新题/延迟复测，保留研究项目、复习卡、个人记录和备份。 |

## 快速开始

需要 Node.js 22 或更高版本。网页部分没有 npm 运行依赖。

```sh
git clone https://github.com/fisheryu0522-code/rangemind.git
cd rangemind
npm start
```

打开 [http://127.0.0.1:8731/](http://127.0.0.1:8731/)。也可以在 Windows 中运行 `Start-PokerLab.cmd`。默认仅监听本机。

干净克隆可以启动工作台、阅读指南、编辑范围、建立局面和记录训练输入。**求解器必须先从源码构建；CUDA 权益和本地语言模型需要另行安装依赖。** 仓库不包含 Windows 可执行程序、GPU 库、模型权重、预解策略树或个人训练记录。未安装的引擎不会变成预生成演示答案，具体步骤见 [BUILD.md](docs/BUILD.md)。

```sh
npm run test:core
```

基础测试不需要 GPU 或原生引擎，覆盖扑克组合、牌力、输入校验、手牌重建和范围存储。`npm test` 为完整测试集，需要已构建的 CPU 引擎与可选依赖；GPU 专项应按测试文件要求显式启用。完整测试与基础测试不能混称。

## 为什么把“解释”放在求解之后

1. 先明确范围、筹码、抽水与有限下注尺寸树，避免缺失假设被默默补成“GTO”。
2. 求解策略，再独立重建联合机会概率、节点到达、终局收益与信息集最佳响应。
3. 解释绑定实际结果中的节点、组合、动作与后续行动；不能从最高动作频率推断可信行动 EV。
4. 用户先预测、写理由，再看证据、修改规则并复测。已经看过的答案与未见过的新题分别记录。

## 数学与产品边界

- 求解针对输入定义的有限博弈。未包含的下注尺寸、范围错误和真实对手偏差不会被一个很小的求解残差消除。
- 多人 CFR 没有一般性的 Nash 收敛保证。结果显示实际最佳响应诊断，不承诺达到全游戏均衡。
- “完整机会枚举”不等于“精确均衡”。抽样误差、优化残差、下注树抽象和范围假设是不同误差来源。
- 尚无完整多人翻牌三街求解、自动全翻前 GTO 库、任意赌场规则支持或实战盈利保证。
- 现场记谱当前针对无 ante、无 straddle 的支持规则；输入含未支持规则应明确修正或拒绝。
- 这是离桌学习与复盘工具，不提供扑克客户端自动操作或实时作弊功能。
